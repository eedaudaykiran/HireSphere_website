Our Story

Built by a developer,
for every developer.

HireHub started as a learning project — a full-stack Django job portal inspired by Naukri.com, built from scratch by Udaykiran as part of his journey as a junior Python full-stack developer.

What began as a hands-on exercise in Django 5.2, SQLite, and responsive frontend design grew into a fully-featured recruitment platform complete with employer dashboards, real-time applications, salary management, and a 14-category job filtering system.

Mission & Goals

What we're building toward

HireHub isn't just a portfolio project — it's a blueprint for what a modern, transparent, developer-first job portal should look like.

🎯
Transparent Hiring
Every job shows real salary data or clearly marks it as "Not Disclosed." No dark patterns, no bait-and-switch — candidates deserve honest information from the first click.
⚡
Lightning-Fast Search
14 filter categories, instant checkbox filtering with Django ORM Q objects, and GET-based form submission ensures search results are shareable, bookmarkable, and blazing fast.
🏗️
Clean Architecture
Django 5.2 with a single reusable core app, well-structured models, class-based views, and a template hierarchy that any developer can pick up and extend.
📊
Employer Insights
Real-time dashboards, application pipeline tracking, PDF/Excel report exports, and interview scheduling — employers get the analytics they need to hire smarter.
🔒
Role-Based Access
Candidates and employers live in separate worlds with custom decorators, permission checks, and context-aware redirects that make the UX feel purpose-built for each user type.
🌐
India-First Design
Salary in LPA, cities like Hyderabad, Bangalore, Mumbai baked into filters, and a category system built around the Indian job market — not a generic Western template.
Key Features

Everything a job portal needs

From candidate applications to employer analytics — HireHub ships with a complete recruitment stack.

🔍
Smart Job Filtering
14 filter categories including work mode, salary range, location, company type, education, industry, and role category. Checkboxes auto-submit with onchange="submitFilter()" — no Apply button needed.
Django ORM Q Objects
📋
Employer Dashboard
Full recruitment pipeline — post jobs, view applicants, track status from Applied → Screening → Shortlisted → Interview → Offer. Real-time AJAX polling keeps counts fresh without page reloads.
Real-Time AJAX
💰
Salary Management
salary_disclosed boolean flag with a salary_display property that is the single source of truth. MinValueValidator blocks negatives. Forms auto-set "Not Disclosed" when both fields are blank.
Clean Data Model
📄
Resume & Reports
Candidates upload resumes at application time. Employers export full recruitment reports as styled PDF (ReportLab) or multi-sheet Excel (openpyxl) with one click from the reports dashboard.
PDF + Excel Export
Project Roadmap

How it came together

HireHub was built feature by feature, bug by bug — each challenge teaching a real-world Django lesson.

Phase 1
Core Models & Auth
Job, UserProfile, Application models. Role-based login with employer/candidate split. Custom decorators for access control.
Phase 2
Job Listings & Filtering
Remote jobs page with 14-category filter system, pagination preserving GET params, and instant checkbox filtering.
Phase 3
Employer Dashboard
Full pipeline dashboard, application tracking, interview scheduling, messages inbox, and real-time AJAX data updates.
Phase 4
Salary & Reports
salary_disclosed flag, salary_display property, PDF/Excel export, and fixing 19 jobs with incorrect salary data via shell.
Next Up
Email Notifications & AI Matching
Candidate–job skill matching, email alerts for new applications, and a recommendation engine powered by Django signals.
